# Joemar Dacles - Personal Portfolio Website
Simple, Responsive, and Interactive Website built with pure HTML5, CSS3, and JavaScript.

## 📁 File Structure
- `index.html` - The semantic HTML5 webpage structure
- `style.css`  - Responsive styling (Flexbox, CSS Grid, Dark Mode CSS variables)
- `script.js`  - Interactive behaviors (Counter, dynamic filters, form validation, theme switcher)

## 💻 How to Run in VS Code Studio:
1. Download or place these files in a single folder named `my-portfolio`.
2. Open VS Code.
3. Click **File > Open Folder...** and select the `my-portfolio` folder.
4. Install the extension **Live Server** (by Ritwick Dey) in VS Code.
5. Right-click `index.html` and click **Open with Live Server**.
6. The website will open in your default browser at `http://127.0.0.1:5500/index.html`!

## 🚀 How to Deploy Online with Netlify Drag and Drop:
1. Open your browser and go to: https://app.netlify.com/drop
2. Drag and drop the `my-portfolio` folder into the drop zone.
3. In 10 seconds, Netlify will generate your live online link!
4. Go to **Site configuration > Change site name** to set your custom URL (e.g. `joemar-portfolio.netlify.app`).
